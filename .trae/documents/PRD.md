## 1. 产品概述

数据要素流通订阅管理 Web 应用，为数据采购方提供一站式订阅管理平台，帮助企业高效管理已订阅的数据产品和交付服务，实现全生命周期的数字化管控。

- 核心目标：解决数据采购方在订阅管理过程中面临的多产品分散管理、交付不透明、额度难追踪、费用统计复杂等痛点
- 目标用户：企业数据采购部门、数据管理员、IT 运维人员、财务人员
- 市场价值：提升数据要素流通效率，降低管理成本，保障数据质量，赋能数据驱动决策

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 超级管理员 | 企业数据部门负责人 | 全部功能权限、审批权限、成员管理 |
| 普通管理员 | 数据订阅经办人 | 产品订阅、额度申请、质量反馈、账单查看 |
| 普通成员 | 数据使用人员 | 查看订阅信息、接收交付提醒、下载服务报告 |
| 财务人员 | 财务部门人员 | 账单查看、费用统计、成本汇总 |

### 2.2 功能模块

1. **产品订阅**：订阅总览、产品目录、申请开通、订阅状态追踪、接收人配置
2. **交付日历**：日历视图、交付批次跟踪、交付提醒、交付详情查看、服务报告下载
3. **调用额度**：额度总览、剩余额度检查、使用趋势、临时扩容申请、多产品使用量对比
4. **质量反馈**：问题提交、问题列表、处理进度跟踪、历史记录、质量评分
5. **费用账单**：账单列表、账单明细、费用趋势、部门成本汇总、账单导出
6. **权限成员**：成员列表、角色管理、权限配置、添加/移除成员
7. **续订审批**：待办审批、发起续订/停订、审批流程、审批历史

## 3. 核心流程

### 3.1 产品订阅流程

用户浏览产品目录，选择意向产品，查看产品详情，确认后提交开通申请，系统自动流转审批，审批通过后产品生效，用户可配置交付接收人。

```mermaid
flowchart LR
    A["浏览产品目录"] --> B["查看产品详情"]
    B --> C["提交开通申请"]
    C --> D["系统自动审批"]
    D --> E["审批通过"]
    E --> F["配置接收人"]
    F --> G["订阅生效"]
```

### 3.2 质量反馈流程

用户发现数据质量问题，提交问题反馈，系统通知数据提供方处理，处理过程实时同步，问题解决后用户验收评分。

```mermaid
flowchart LR
    A["发现质量问题"] --> B["提交问题反馈"]
    B --> C["通知提供方处理"]
    C --> D["提供方处理中"]
    D --> E["问题解决"]
    E --> F["用户验收评分"]
```

### 3.3 续订审批流程

系统在订阅到期前自动提醒，用户可发起续订或停订申请，审批流程根据配置自动流转，审批通过后系统自动更新订阅状态。

```mermaid
flowchart LR
    A["到期提醒"] --> B["发起续订/停订申请"]
    B --> C["审批流转"]
    C --> D["审批通过"]
    D --> E["更新订阅状态"]
    E --> F["生成新账单"]
```

## 4. 用户界面设计

### 4.1 设计风格

**设计理念**：采用现代企业级 SaaS 设计语言，融合科技感与专业感，以数据可视化和高效交互为核心。

- **主色调**：深海蓝 `#0F172A`，代表专业、可信、稳重
- **辅助色**：科技青 `#06B6D4`、活力橙 `#F97316`、成功绿 `#10B981`、警示红 `#EF4444`
- **背景色**：深灰渐变 `#0F172A` → `#1E293B`，营造沉浸式数据管理氛围
- **字体**：展示字体使用 `Space Grotesk`，正文字体使用 `Inter`
- **按钮风格**：圆角 6px，悬浮有微缩放和发光效果
- **布局风格**：左侧导航栏 + 顶部操作栏 + 主内容区，卡片式信息承载
- **图标风格**：使用 Lucide 线性图标，统一 24px 尺寸，颜色与主题呼应
- **动效风格**：页面加载采用渐进式入场动画，卡片悬浮有轻量上浮和阴影加深，数据变化有数字滚动动画

### 4.3 响应式设计

- **设计原则**：桌面端优先设计，逐步向下适配平板和移动端
- **断点设置**：
  - 桌面端：≥ 1280px，完整三栏布局
  - 平板端：768px - 1279px，导航栏可折叠，表格横向滚动
  - 移动端：< 768px，底部标签导航，卡片单列布局
- **触控优化**：移动端按钮最小 44px × 44px，支持手势滑动切换标签页

### 4.4 数据可视化设计

- **图表库**：使用 Recharts 实现交互式数据可视化
- **图表类型**：
  - 额度展示：环形进度图，渐变填充
  - 趋势分析：面积折线图，平滑曲线
  - 对比分析：分组柱状图，动画排序
  - 成本构成：环形饼图，支持下钻
- **交互特性**：图表支持悬浮显示详情、点击图例切换系列、数据响应式更新动画
